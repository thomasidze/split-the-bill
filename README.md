# Делим счёт

Telegram Mini App, которое делит общие расходы внутри группового чата. Добавляете бота в группу,
создаёте событие («Баня 21.06»), вносите расходы по чеку. Каждый отмечает, что он ел или пил,
а приложение считает, кто кому сколько должен, с минимумом переводов.

## Возможности

- **События внутри чата.** Каждый чат видит только свои события. Участником события становится тот,
  кто нажал «Я участвую», добавил расход или отметил позицию.
- **Расходы по чеку.** Название, кто платил, позиции с ценой и количеством, чаевые (0 / 5 / 10 / 15 % или своё)
  и фото чека.
- **Отметка позиций.** Каждый отмечает своё: «Моё» для одной штуки или «− / +» для нескольких.
  Экран обновляется сам раз в 5 секунд, а строка «Не разобрано» показывает, сколько денег ещё никто не взял.
- **Позиции «на всех».** Например, угли или аренда — делятся поровну между участниками события.
- **Закрытие расхода.** Плательщик закрывает расход и решает, что делать с неразобранным остатком:
  поделить поровну или оставить на себе.
- **«Кто кому».** Долги по событию взаимозачитываются, переводов получается не больше, чем участников минус один.
  Должник жмёт «Я перевёл», получатель — «Подтвердить».
- **Уведомления в чат.** О каждом новом расходе бот пишет в группу, кнопка ведёт сразу на этот расход.
- **Оформление.** У каждого события свой цвет, у каждого человека — свой цвет кружка.
  Светлая и тёмная темы Telegram подхватываются сами.
- **Суммы сходятся до копейки.** Все деньги хранятся в копейках, при делении остаток раздаётся по копейке
  методом наибольшего остатка.

## Как это выглядит в чате

1. Бота добавляют в группу — он присылает приветствие с кнопкой «Открыть» и предлагает его закрепить.
   Если приветствие потерялось, работает команда `/app` (если в группе несколько ботов — `/app@имя_бота`).
2. Кнопка «Открыть» запускает приложение со списком событий этого чата.
3. Если группу превратили в супергруппу (Telegram при этом меняет id чата), приложение само перенесёт данные,
   старые кнопки «Открыть» продолжат работать.

Бот нужен только для запуска приложения и уведомлений; вся работа идёт в самом Mini App.

## Стек

- **Python 3.12**, [FastAPI](https://fastapi.tiangolo.com/) и Uvicorn
- **[aiogram 3](https://docs.aiogram.dev/)** — бот, получает обновления через вебхук в том же процессе
- **SQLAlchemy 2 + SQLite** — одна база в файле
- **Jinja2 + [htmx](https://htmx.org/)** — сервер отдаёт готовые куски HTML, своего фронтенд-фреймворка нет
- **[Telegram Web Apps](https://core.telegram.org/bots/webapps)** — кнопки «Назад» и главная кнопка Telegram,
  вибрация, цвета темы
- **pytest** — тесты

```
app/
  main.py        — создание приложения и вебхук бота
  config.py      — настройки из .env
  db.py, models.py — база и таблицы
  auth.py        — проверка подписи Telegram (initData) и членства в чате
  calc.py        — расчёты: доли, чаевые, остаток, балансы, переводы (без базы и сети)
  services.py    — работа с базой поверх calc.py
  bot.py         — обработчики бота и уведомления
  colors.py      — цвета событий и людей
  web.py         — шаблоны, сессия базы, ошибки
  routes/pages.py — экраны и действия
templates/       — HTML-экраны
static/          — app.css и app.js
tests/
docs/superpowers/ — спецификация и план разработки
```

## Быстрый старт

### 1. Установка

Нужен менеджер пакетов [uv](https://docs.astral.sh/uv/). Нужную версию Python (3.12, она закреплена
в `.python-version`) он скачает сам.

macOS и Linux:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Windows (PowerShell):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Если после установки команда `uv` не находится, откройте новое окно терминала.
Затем в папке проекта:

```bash
uv sync
```

### 2. Бот в @BotFather

1. `/newbot` — придумайте название и имя бота (заканчивается на `bot`). BotFather пришлёт **токен**.
2. `/setjoingroups` → бот → `Enable`, чтобы бота можно было добавить в группу.
   Режим приватности (`/setprivacy`) менять не нужно.
3. `/newapp` → бот → название, описание и картинка 640×360 (демо-гифку можно пропустить командой `/empty`).
   - **Web App URL** — публичный HTTPS-адрес приложения. Пока его нет, введите `https://example.com`.
   - **short name** — короткое имя латиницей, например `splitbill`.

Адрес потом меняется так: `/myapps` → бот → приложение → `Edit Web App URL`.

### 3. Файл `.env`

```bash
cp .env.example .env
```

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `BOT_USERNAME` | имя бота без `@` |
| `APP_SHORT_NAME` | short name из `/newapp` |
| `APP_URL` | публичный HTTPS-адрес приложения (`/` на конце уберётся сам) |
| `WEBHOOK_SECRET` | случайная строка из `A-Z a-z 0-9 _ -`, например вывод `python3 -c "import secrets; print(secrets.token_hex(16))"` |
| `DB_PATH` | файл базы SQLite, по умолчанию `data/app.db` |

`.env` содержит секреты и не попадает в git — никому его не отправляйте.

### 4. Запуск на своём компьютере

Telegram открывает Mini App только по HTTPS и должен достучаться до вебхука, поэтому нужен туннель —
программа, которая даёт вашему компьютеру временный публичный адрес. Подойдёт любой из двух:

- **[localhost.run](https://localhost.run/)** — ничего ставить не нужно, работает через SSH:

  ```bash
  ssh -R 80:localhost:8000 nokey@localhost.run
  ```

  Адрес будет вида `https://что-то.lhr.life`.
- **[cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)**:

  ```bash
  cloudflared tunnel --url http://localhost:8000
  ```

  Адрес будет вида `https://что-то.trycloudflare.com`.

Дальше:

1. Окно с туннелем не закрывайте. Впишите его адрес в `.env` (`APP_URL=...`) и в BotFather (`Edit Web App URL`).
2. Во втором окне терминала запустите приложение:

   ```bash
   uv run uvicorn --factory app.main:build --port 8000
   ```

   При старте оно само сообщает Telegram адрес вебхука `{APP_URL}/tg/webhook`.
3. Добавьте бота в группу — придёт приветствие с кнопкой «Открыть».

Адрес бесплатного туннеля меняется при каждом перезапуске. Тогда обновите его в `.env` и в BotFather
и перезапустите приложение.

## Деплой на сервер

Подойдёт любой хостинг с HTTPS-адресом и постоянным диском (VPS или сервис с volume). Приложение упаковано
в `Dockerfile`:

```bash
docker build -t split-bill .
docker run -d --name split-bill -p 8000:8000 \
  -v split-bill-data:/data \
  -e BOT_TOKEN=... \
  -e BOT_USERNAME=... \
  -e APP_SHORT_NAME=... \
  -e APP_URL=https://ваш-домен \
  -e WEBHOOK_SECRET=... \
  split-bill
```

- `APP_URL` должен совпадать с адресом в BotFather. HTTPS обычно даёт хостинг или обратный прокси
  (Caddy, nginx), который пересылает запросы на порт 8000.
- Внутри контейнера база лежит в `/data/app.db`. Без тома `/data` она пропадёт при пересоздании контейнера.
  Если передаёте настройки через `--env-file .env`, уберите из файла `DB_PATH` или укажите `DB_PATH=/data/app.db`.
- Ограничьте размер запроса на прокси, например 15 МБ (nginx: `client_max_body_size 15m;`): фото чека
  принимается до 10 МБ.
- Запускайте один экземпляр: SQLite не рассчитана на несколько копий с общей базой.

## Как считаются деньги

- **Позиция.** Если отмечено не больше штук, чем есть, каждый платит за свои штуки, остальное — «не разобрано».
  Если отметили больше, чем есть, стоимость делится пропорционально отмеченному.
- **Чаевые** начисляются пропорционально доле каждого; «не разобрано» тоже показывается с чаевыми.
- **«На всех» и остаток при закрытии «поровну»** делятся между **текущими** участниками события.
  Доли пересчитываются каждый раз: если кто-то присоединится позже, они изменятся даже у закрытых расходов.
  Поэтому перед закрытием попросите всех нажать «Я участвую».
- **Балансы** учитывают только подтверждённые переводы. Список «Кто кому» строится жадно: наибольший должник
  платит наибольшему кредитору, пока долги не кончатся.

Подробности — в [спецификации](docs/superpowers/specs/2026-11-01-split-bill-design.md).

## Если что-то не работает

- **«Открой приложение заново из чата»** — подпись Telegram устарела. Закройте приложение и откройте снова
  кнопкой «Открыть» или командой `/app`. Из обычного браузера приложение не откроется.
- **«Бот удалён из чата»** — верните бота в группу, приветствие придёт заново, данные сохранятся.
- **«Это доступно только участникам чата»** — вы не в этом чате. Если вас только что добавили,
  подождите до 5 минут.
- **«Telegram не отвечает, попробуй ещё раз»** — не удалось проверить членство в чате. Повторите через пару секунд.
- **Нет приветствия при добавлении бота** — проверьте, что приложение запущено, туннель работает, `APP_URL`
  верный и после его смены приложение перезапускали.
- **cloudflared пишет `i/o timeout` или `TLS handshake ... EOF`** — часто мешает VPN: его DNS или сеть
  не пропускают соединения cloudflared. Выключите VPN на время запуска или используйте localhost.run.
- **При запуске `Cannot connect to host api.telegram.org`** — из вашей сети недоступны серверы Telegram.
  Запускайте приложение там, где Telegram API доступен (например, с VPN).
- **`uv` пытается собрать `pyyaml` и просит Microsoft C++ Build Tools (Windows)** — uv взял слишком новый Python.
  Выполните `uv python pin 3.12` и запустите снова.
